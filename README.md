# MG7
## Devlog
1. The TreeOfBirds script is connected to the Tree GameObject and contains an array of all the birds. The script checks every frame by looping through all the birds in the array and uses vectors to check if each bird is too close to the player when it is below the interactionDistance variable. If a bird is too close, it sets the bird active which makes the player see it.
